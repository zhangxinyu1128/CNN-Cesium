# AI+ 台风研判智能助手

## 模块定位

项目新增的 AI+ 能力不是普通 FAQ，也不是把大模型包装成新的台风预报模型。它是一个“基于项目知识检索与实时状态上下文的台风研判智能助手”：用户可以在三维地图右下角提问，助手会同时参考项目证据和当前页面状态，解释模型口径、预测点、ERA5 环境背景和历史误差范围。

## 可验证的创新点

1. **证据约束问答**：模型说明、数据划分、实验指标、共形校准和使用边界被整理为本地知识卡片；回答附带引用来源。
2. **当前状态注入**：助手接收当前台风、观测时间、预测时效、预测位置、90% 历史校准半径和 ERA5 500/850 hPa 风场摘要，不回答脱离页面状态的泛泛问题。
3. **严格模型口径**：在线 `/api/predict` 仍是纯轨迹一维 CNN；ERA5 500/850 hPa 是历史融合实验对照，助手会主动阻止两者被混为一谈。
4. **离线可演示、云端可增强**：默认使用本地检索和模板化回答，不需要外部密钥；配置 DeepSeek 后，只让大模型根据已检索证据组织自然语言，调用失败自动回退本地回答。

## 运行方式

无需配置即可使用本地回答。若要启用 DeepSeek，在后端进程环境中设置：

```text
TC_ASSISTANT_PROVIDER=deepseek
DEEPSEEK_API_KEY=你的密钥
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-chat
```

密钥只放在后端，前端不会读取或发送密钥。接口为 `POST /api/assistant/ask`，请求包含 `question` 和精简的 `context`。

## 答辩表述

> 我们新增了“台风研判智能助手”。它不是普通聊天框，而是把项目的模型说明、实验指标、数据来源和限制做成可检索证据卡片，再绑定当前选中的台风状态、预测时效、ERA5 风场和历史校准范围。用户可以直接追问“当前在线模型是否使用 ERA5”“24 小时误差如何解释”等问题，系统返回带来源的解释。默认本地证据回答，配置 DeepSeek 后由大模型完成语言组织，因此既能离线演示，又能保持结果可追溯。

## 边界

- 不宣称已经接入卫星、其他国家气象局、多模式预报或完整区域风场。
- 不把 ERA5 历史融合实验说成在线模型已经使用 ERA5。
- 90% 误差范围是历史校准覆盖参考，不是实时灾害概率或官方预警。
