# 官方预报对比验收报告

## 1 结论

已使用 `official_forecast` 中的 JTWC 2025 f-deck 官方预报，与项目冻结测试集中的模型结果进行同台风、同起报时刻、同验证真值对比。

本轮严格可比样本为 471 个预测窗口，覆盖 26 个台风。结果显示，当前阶段三 ERA5 500/850 hPa 环带模型尚未超过 JTWC 官方预报，官方预报在 12/24/36 小时均明显更优。该结论用于定位模型改进方向，不作为项目失败判断，也不外推到其他年份。

## 2 数据与配对口径

| 项目 | 口径 |
| --- | --- |
| 官方机构 | JTWC |
| 产品 | ATCF f-deck 官方预报路径 |
| 资料年份 | 2025 年 |
| 验证真值 | `official_forecast/best_track_points.csv` |
| 起报匹配 | 台风编号 + 起报时刻精确匹配 |
| 有效时效 | 12、24、36 小时 |
| 误差 | 预测中心与验证中心的大圆距离，单位 km |
| 测试划分 | 项目冻结测试集，不重新随机切分 |

官方归档没有 6、18、30 小时预报点，因此这些时效不进入官方对比表。

## 3 结果

| 时效 | JTWC 官方预报 MAE | 仅轨迹 CNN MAE | 轨迹 + ERA5 500/850 MAE | 官方样本数 |
| ---: | ---: | ---: | ---: | ---: |
| 12h | 48.6 | 125.0 | 120.4 | 455 |
| 24h | 67.2 | 214.2 | 184.6 | 424 |
| 36h | 84.0 | 355.2 | 308.2 | 378 |

ERA5 500/850 模型相对仅轨迹 CNN 的 MAE 改善约为 3.6%、13.8%、13.2%，说明风场融合有效，但距离官方业务预报仍有较大差距。

## 4 结果解释

1. JTWC 官方预报使用业务化预报系统和更多实时资料，不能简单与当前离线 CNN 的输入条件等同。
2. 当前 ERA5 特征是沿台风中心匹配的风场样本，并非完整区域风场；模型没有使用实时数值预报、卫星观测或多模式集合信息。
3. 当前结果证明“加入 500/850 hPa 风场比仅使用轨迹更好”，但不能证明 CNN 已经优于官方预报。
4. 2025 年真值表来自审计后的标准化最佳路径表，官方预报和模型使用同一验证真值；不得把官方预报自身误差直接当作模型误差。

## 7 下一步改进

1. 优先增加起报时刻可用的环境场特征，而不是只使用中心点风场。
2. 增加风切变、环境引导流和更大空间范围的 500/850 hPa 风场编码。
3. 使用经过审计的海岸线数据补充登陆阶段分类，并对登陆前后误差分层。
4. 补充 2020—2024 年可追溯的官方预报产品后，再进行跨年份比较。
5. 在完成多年份验证前，前端和答辩材料统一标注“2025 年 JTWC 对比”，不写成多年业务结论。
